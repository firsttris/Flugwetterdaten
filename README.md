> Aktuelle Wetterinformationen zum Surfen an der Staustufe am Flughafen Baden-Airpark als responsive WebApp.

## Live Demo

**[wetter.teufel-it.de](https://wetter.teufel-it.de)**

## Features

- **Flugwetterdaten** - Direkter Zugriff auf das Wetterbild des Baden-Airpark (QNH, Temperatur, Windrichtung, Bewölkung etc.)
- **Wassertemperatur** - Aktuelle Wassertemperatur vom LUBW
- **Wasserstand** - Aktueller Pegelstand mit Trend-Anzeige (steigend/fallend/stabil)
- **Mobile optimiert** - Vollständig responsive für alle Geräte
- **Zero Dependencies** - Nur vanilla JavaScript, HTML & CSS

## Technologie

Das Projekt verwendet bewusst keine externen Abhängigkeiten:

- Vanilla JavaScript für API-Aufrufe und DOM-Manipulation
- CSS Custom Properties für konsistentes Theming
- CSS Grid & Flexbox für das responsive Layout
- Google Fonts (Inter) für die Typografie
